Premium Management

Use the following actions to manage student memberships.

Activate Premium

Activate a free student's membership for a specified number of days.

Extend Premium

Add days to an existing membership expiry date.

Add Days

Add extra membership days. If the membership has expired, the new expiry period starts from the current date.

Deactivate Premium

Immediately remove the student's Premium access.

PayHere Verification

Before activating Premium, independently verify the student's payment in your PayHere merchant account and match the transaction to the correct student email.

Manually activating Premium through this dashboard does not automatically verify or record a PayHere transaction.
