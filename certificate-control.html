Manage how many practice questions a student must complete before the certificate unlocks.

How this works

The certificate requirement is stored in Cloudflare D1.

For example, if you set the requirement to 500, students need to complete 500 practice questions.

If you later change it to 1000, the certificate requirement automatically becomes 1000.

Your existing Progress Worker and AI MCQ Worker are not changed by this page.
